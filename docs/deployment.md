# Deployment
Deploy web and API separately behind HTTPS. Required server secrets: DATABASE_URL and SESSION_SECRET. Run `npm run db:migrate` before API rollout, then health-check `/api/health`. Set APP_ORIGIN/ALLOWED_ORIGINS to explicit HTTPS origins and VITE_API_URL at client build time. Keep staging and production databases/secrets separate. Back up PostgreSQL with scheduled pg_dump plus provider snapshots; test restore to staging. Centralize stdout/stderr logs with request IDs and alert on health/error-rate failures. No production domain/hosting credentials are committed; permanent hosting/DNS remains an external deployment authorization.
